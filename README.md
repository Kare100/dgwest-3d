# DG West Westlands in 3D

An interactive 3D concept site for DG West, a luxury residential tower in Westlands, Nairobi.

- A realistic tower in a modern Kenyan style: white slab bands, grey stone cladding, beige plaster, timber louvres and glass balconies.
- Hover a floor to see what's on it, then click to fly in to a furnished cutaway apartment (studio, 1-bed or 2-bed).
- Each apartment has a card with price, specs, features and a viewing button. Arrow keys move between levels; Replay reruns the build.

## Run it

It's a single `index.html` with three.js loaded from jsDelivr, so there's no build step.

```
python -m http.server 8000
```

Then open http://localhost:8000. It deploys as-is to Vercel or any static host.

## Note

This is a design concept. Prices and some details are illustrative; check with the developer for real availability.
